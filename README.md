# SDC435-3.5-Amazon-Cassandra-CRUD

## AmazonCRUD.py

AmazonCRUD.py is a Python application that connects to an Apache Cassandra database and performs CRUD operations on Amazon review data.

The application creates the Amazon keyspace and the Reviews and ProductCategories tables, imports the JSON dataset, displays product categories and review counts, executes user-entered CQL SELECT queries, allows table columns to be added or removed, and allows tables and the Amazon keyspace to be deleted.
